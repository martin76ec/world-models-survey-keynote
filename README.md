# Survey of World Models — Keynote

Motion presentation for *Survey of World Models: A Proposed Definition, Evidence Criteria, and a Taxonomy by Prediction Target* (Martín Larrea; tutor: Felipe Grijalva).

**Live:** https://martin76ec.github.io/world-models-survey-keynote/

## Controls
- Advances only on `→` / click (`←`: previous) · animations loop on each slide
- `Space`: pause/resume animations · `Home`: first slide · `#N` in the URL opens slide N

## GitHub Pages
Single static `index.html` (no build step). In the repo: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.
